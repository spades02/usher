<Steps>

1. **Install.** Usher needs Node 22.13+ and works with any [Standard Schema](https://standardschema.dev) library. Zod 4 is shown here.

   ```sh
   npm install @usherjs/core zod
   ```

2. **Define tools.** These are the actions an agent may take for a customer. `effect` is required: `read`, `write` or `destructive`. Destructive tools ask the customer to approve each call.

   <Code code={tools} lang="ts" title="tools.ts" />

3. **Create Usher.** Bridge it to your login, give it your database, and pick the guardrails.

   <Code code={usher} lang="ts" title="usher.ts" />

   `USHER_SECRET` signs consent and approval forms. Generate one with `openssl rand -base64 32`.

4. **Mount it.** Usher serves `/api/usher/*`, plus two discovery documents under `/.well-known/`. In Next.js, that's two route files with the same content:

   <Code code={nextRoute} lang="ts" title="app/api/usher/[...usher]/route.ts" />

   Other frameworks: see [Frameworks](/guides/frameworks/).

5. **Check the deployment** the way an agent will see it:

   ```sh
   npx @usherjs/core doctor https://your-app.example
   ```

6. **Connect an assistant.** In Claude, ChatGPT or Cursor, add a custom connector with the URL `https://your-app.example/api/usher/mcp`. You'll be sent to your own login, then to a consent page listing your tools. Ask the assistant to list your orders.

   To show customers how, drop [`<usher-connect>`](/guides/customer-ui/) on a help page.

</Steps>
