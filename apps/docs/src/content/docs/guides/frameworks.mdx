Usher is one web-standard `handler(Request) → Response`. It must receive:

- everything under **`/api/usher/*`** (your `basePath`), and
- **`/.well-known/oauth-protected-resource/*`** and
  **`/.well-known/oauth-authorization-server/*`**, which agents look up at
  your origin's root.

`usher.matches(pathname)` tells you whether a path is Usher's. Other
`/.well-known` files (Apple, Android, `security.txt`) are never claimed.

## Behind a proxy

Set `baseUrl` to your public origin, e.g. `https://shop.example`. Usher uses
it for every URL it advertises, and for its same-origin checks. With
`@usherjs/core/node`, `trustProxy: true` honors `X-Forwarded-Proto` and
`X-Forwarded-Host`. Only enable it behind a proxy that sets them.

Then check from the outside:

```sh
npx @usherjs/core doctor https://shop.example
```

## Not JavaScript?

Rails, Django, Laravel, Go and .NET apps run Usher as a separate process.
See [Standalone server](/guides/standalone/).
